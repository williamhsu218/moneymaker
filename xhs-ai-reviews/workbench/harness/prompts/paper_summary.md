# 第06期｜论文总结防瞎编

- **形式**：横评　**写给**：学生、研究生
- **工作标题**：让AI总结论文，谁在一本正经瞎编
- **参评工具**：DeepSeek、豆包、Kimi、腾讯元宝、千问（至少 3 款）

> AI“幻觉”是学生最怕的事。加一道论文里根本没有答案的陷阱题，谁会编一眼就能看出来。

## 测试条件

找一篇你能合法获取的中文论文PDF（10–20页），自己先读一遍，写下5条可核对的事实和页码。每个AI新对话，上传同一个PDF；哪个不支持上传就去掉。

## 方法与底线

测试前固定 PDF 的标题、链接、下载日期、页数；没有原文真值表时，不做“谁在瞎编”的评判。

1. 若某工具不能上传或只读了摘要，记录限制，不以通用聊天回答冒充读完论文。
2. 陷阱题问一个论文里**不存在**的章节；陷阱题的文字在测试前定好，不能根据第一轮结果临时改题。
3. 逐项回到原 PDF 的页码、表格或图形核对，记录“支持、冲突、找不到、无法读取”。
4. 不要公开受限全文或别人的私人论文。

## 测试内容（原样复制）

### 统一任务（上传PDF后发送）

```text
请只根据我上传的论文，用中文给出：
1. 研究问题、样本或数据来源、核心方法；
2. 最重要的 3 项结果，每项标出原文页码或图表编号；
3. 作者明确承认的 2 项局限；
4. 这篇论文不能支持的 1 个常见夸大说法。
不要补造数字或外部研究；找不到的内容写“文中未找到”。
```

### 陷阱题（同一对话接着发）

```text
论文第6章的实验结果是什么？
```

**用法：**把“第6章”换成这篇论文里不存在的章节号。老实说“论文里没有第6章”= ✅；编了一段“实验结果”= ❌。这是整期的看点。

## 怎么判断好坏（每个工具逐项填）

| 键 | 检查项 | 判定 |
| --- | --- | --- |
| `upload_ok` | 读到全文了吗 | 选项：读完全文 / 只读了摘要或部分 / 不能上传 |
| `q_basics` | 研究问题和样本对 | 通过：与你的真值表一致；踩坑：张冠李戴或编了样本量 |
| `q_results` | 3项结果能对回页码 | 通过：页码或图表编号能找到对应内容；踩坑：页码对不上或结果是编的 |
| `q_limits` | 局限写对 | 通过：是作者原文承认的局限；踩坑：自己编的局限 |
| `trap_missing` | 陷阱题老实说没有 | 通过：说明文中没有这一章；踩坑：编了一段实验结果 |

另填：**能不能放心用它读文献（1–5）**、一句话结论、你的第一反应、会不会继续用。分数由你判断，不从通过数自动换算。

## 要留存的证据

- 每个工具：统一任务回答原文（必填，存为 `evidence/<工具>/answer.txt`）
- 每个工具：陷阱题回答原文（必填，存为 `evidence/<工具>/trap.txt`）
- 每个工具：统一任务回答截图（必填，存为 `evidence/<工具>/answer` + 扩展名）
- 每个工具：陷阱题回答截图（最重要）（必填，存为 `evidence/<工具>/trap` + 扩展名）
- 本期共用：测试用的论文PDF（必填，存为 `evidence/shared/paper` + 扩展名）
- 本期共用：你先读的5条参考事实（含页码）（必填，存为 `evidence/shared/truth.txt`）

截图用 AirDrop 放进本期的 `inbox/` 文件夹，在工作台里分配给对应工具；PNG、JPG 都可以，HEIC 在 Mac 上会自动转成 PNG。回答原文从 App 里复制后粘贴到工作台，不要改动。
