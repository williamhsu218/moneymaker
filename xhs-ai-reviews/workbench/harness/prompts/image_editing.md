# 第09期｜AI修图横评

- **形式**：横评　**写给**：所有人
- **工作标题**：同一张照片让3个AI修，差别好大
- **参评工具**：豆包、腾讯元宝、美图秀秀（至少 2 款）

> 修图前后对比天然抓眼球。证件照换底色又是搜索量很大的需求。

## 测试条件

准备2张你自己的照片：一张有路人的阴天风景照，一张正面照（不想露脸可以请朋友帮忙，要征得同意）。只用免费功能。

## 方法与底线

只用本人拍摄或明确获授权的照片；含可识别人脸的，先取得授权。测试前保存未编辑原图。

1. 对同一张原图执行同一个操作；只能用画笔圈选的产品，圈选相近范围并截图记录，交互方式不同要写进限制。
2. 在原图和导出图的同一比例下对比：目标是否消失、主体是否变形、背景是否自然、有没有误删、分辨率是否下降。
3. 不能用预览图充当最终导出成品；记录水印和会员限制。

## 测试内容（原样复制）

### 任务1 消除路人

```text
帮我把照片里背景的路人去掉，其他地方不要动。
```

### 任务2 换天空

```text
把阴天的天空换成晴天蓝天，要自然。
```

### 任务3 证件照换底色

```text
把这张照片换成蓝底证件照，头发边缘要自然。
```

## 怎么判断好坏（每个工具逐项填）

| 键 | 检查项 | 判定 |
| --- | --- | --- |
| `t1_clean` | 路人去干净了 | 通过：没有残影和边缘痕迹；踩坑：有残影、糊块或误删 |
| `t2_natural` | 换天空自然 | 通过：光线和色调一致；踩坑：明显贴图感 |
| `t3_edges` | 证件照边缘自然 | 通过：头发边缘干净；踩坑：头发抠糊或有白边 |
| `face_unchanged` | 脸没被改 | 通过：五官和原图一致；踩坑：被“顺手美颜”或变脸 |
| `paywall` | 免费能不能用 | 选项：全部免费 / 有水印 / 要会员才能保存高清 / 不能用 |
| `minutes` | 用了多久（分钟） | 填数字（最小 0） |

另填：**修完能不能直接发（1–5）**、一句话结论、你的第一反应、会不会继续用。分数由你判断，不从通过数自动换算。
