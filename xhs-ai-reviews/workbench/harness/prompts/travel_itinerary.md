# 第08期｜照着AI攻略出行

- **形式**：教程　**写给**：所有人
- **工作标题**：照着AI做的攻略，我玩了一整天
- **参评工具**：千问、豆包、腾讯元宝（至少 2 款）

> 最“第一手”的内容：真的去走一遍。照片好看，涨粉潜力大，还能加地点吃同城流量。

## 测试条件

选一个周末。把提示词里【】换成你的城市和出发地，所有工具用完全相同的内容。

## 方法与底线

地点营业时间、门票、交通和天气会变化；所有事实以出行当天的官方场馆、交通和地图信息核实。

1. 出行前逐站核对官网或场馆公告，保存核对时间和链接。
2. 实际出行时记录到达时间、真实费用、步数和临时变更。
3. 没有亲自走完路线，只能写“行前核查”，不能写“实地验证”，标题也不能用“我玩了一整天”。
4. 公开时删除精确住址等私人位置。


## 怎么判断好坏（每个工具逐项填）

| 键 | 检查项 | 判定 |
| --- | --- | --- |
| `places_exist` | 地方都还在、开着门 | 通过：每一站核实存在且当天开放；踩坑：推荐了已关闭或当天不开的地方 |
| `booking` | 需要预约的有提醒 | 通过：需预约的站点都提醒了；踩坑：要预约却没提 |
| `transit` | 交通时间靠谱 | 通过：与地图估算相差不大；踩坑：明显低估或路线不通 |
| `budget` | 预算算得清 | 通过：能算出总花费且在300内；踩坑：超预算或没法算 |
| `wrong_facts` | 错误信息条数 | 填数字（最小 0） |

另填：**值不值得照着走（1–5）**、一句话结论、你的第一反应、会不会继续用。分数由你判断，不从通过数自动换算。

## 要留存的证据

- 每个工具：行程原文（必填，存为 `evidence/<工具>/itinerary.txt`）
- 每个工具：行程截图（必填，存为 `evidence/<工具>/itinerary` + 扩展名）
- 本期共用：逐站核查表（地点、官方信息、核对时间、链接）（必填，存为 `evidence/shared/route-check.txt`）
- 本期共用：实际出行记录（花费、步数、翻车点）（可选，存为 `evidence/shared/trip-log.txt`）

截图用 AirDrop 放进本期的 `inbox/` 文件夹，在工作台里分配给对应工具；PNG、JPG 都可以，HEIC 在 Mac 上会自动转成 PNG。回答原文从 App 里复制后粘贴到工作台，不要改动。
