# 第11期｜新品48小时实测

- **形式**：新品　**写给**：所有人
- **工作标题**：【新品名】上线48小时，我先替你试了
- **参评工具**：千问（至少 1 款）

> 大新品发布后尽快出实测，能吃到搜索和推荐的第一波流量。这一期是模板，任何国内能直接用的新品都能套。

## 测试条件

新品线索先在“线索”页核实：官方来源、发布日期、我的账号里能不能用。能用再建这一期，把参评工具改成“新品 + 对照”。

## 方法与底线

本期是机动选题，不预设厂商、型号或排名。社区传闻、匿名榜单和灰度消息只能作为线索，不能据此声称功能已正式上线或性能已提高。

1. 保存官方发布页面、日期、功能说明及当时版本，并在**本人当前账号**确认能用；不能用就记为“暂不可测”，转回线索池。
2. 从做过的题里挑一个固定标尺（比如第1期周报陷阱题），和上次结果比。
3. 仅对验证到的功能下结论；“48小时内发布”是速度目标，不能替代证据。

## 测试内容（原样复制）

### 通用框架：5个任务，30–60分钟

```text
1. 官方主打的功能（官方说它强在哪就测哪）
2. 固定标尺：第1期的周报陷阱题，和上次的结果比
3. 一个你生活里的真实任务
4. 一道陷阱题，看它会不会编
5. 速度和免费额度
```

### 例子：让新模型看一段视频

```text
（上传一段30秒以内你自己拍的视频，比如做饭、街景）
这个视频里发生了什么？按时间顺序说。
第几秒出现了【视频里的某样东西】？
视频里的人说了什么？
视频里那只狗是什么颜色的？
```

**陷阱：**最后一问要选视频里根本没有的东西。老实说“视频里没有狗”= ✅。

## 怎么判断好坏（每个工具逐项填）

| 键 | 检查项 | 判定 |
| --- | --- | --- |
| `headline_feature` | 主打功能真的强 | 通过：官方说的能力在我的任务里成立；踩坑：宣传和实际不符 |
| `weekly_regression` | 周报标尺和上次比 | 选项：比上次好 / 差不多 / 比上次差 / 未测 |
| `trap` | 陷阱题没编 | 通过：老实说没有；踩坑：编了答案 |
| `speed_quota` | 速度和免费额度 | 填文字 |

另填：**值不值得用（1–5）**、一句话结论、你的第一反应、会不会继续用。分数由你判断，不从通过数自动换算。

## 要留存的证据

- 每个工具：各任务回答原文（必填，存为 `evidence/<工具>/answers.txt`）
- 每个工具：关键回答截图（必填，存为 `evidence/<工具>/answers` + 扩展名）
- 本期共用：官方来源（链接、发布日期、版本、功能说明）（必填，存为 `evidence/shared/official.txt`）
- 本期共用：我的账号里能用的截图（必填，存为 `evidence/shared/availability` + 扩展名）

截图用 AirDrop 放进本期的 `inbox/` 文件夹，在工作台里分配给对应工具；PNG、JPG 都可以，HEIC 在 Mac 上会自动转成 PNG。回答原文从 App 里复制后粘贴到工作台，不要改动。

## 要拍/截的素材

- 每个任务的关键回答截图
- 最好录一段屏，展示新功能怎么用

## 图片顺序

1. 封面：“【新品名】，我先试了”（封面）
2. 新在哪：一张图说清（文字卡）
3. 任务截图（每个工具一张截图框）
4. 和旧版或其他AI对比（结果总表）
5. 值不值得用（结论卡）
